Before you start making the actual website, it's good to have a plan in mind. On a paper or a tablet, draw out a layout for your website. What do you want to go where? What text and where; what images and where. Maybe plan out a colour scheme. (Ideally Alex and I would like to see the plan before you start making the website so that we can tell you if there is anything either redundant or missing.) It should not take terribly long to make a simple website. We would like for you guys to make a basic, bare bones website with some text and maybe some placeholder images in a few days. Ideally, your goal should be to have this done by Wednesday/Thursday. Once you have just a bareboned website giving some information about the project (simple HTML, simple CSS), then you can get into some of the more complicated elements of HTML and properties in CSS. This includes adding an element to let the user download the eventually provided .exe file to download the Terrarium application. This page should give you a very basic starting point. Now you can look up how to add different elements; how to link pages together / make a nav bar if you so choose to. Make it fancy! Add animations (can add scroll animations, onclick animations) if you'd like; you can add JavaScript if you'd like. Make it look nice - make sure the website is visually pleasing.
